# ADR-001. Фонова обробка

Контекст:
Справжня AI-модель може відповідати
довше кількох секунд.

Рішення:
Використовувати фонові завдання.
POST повертає HTTP 202 та request_id.
Результат отримуємо через GET.

Наслідки:
Інтерфейс може показувати стан обробки.
Для ПР14 використовується BackgroundTasks.
Надалі для масштабування може знадобитися
окрема черга завдань.
