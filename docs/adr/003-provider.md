# ADR-003. AI-провайдер

Контекст:
ПР14 вимагає перевірки архітектури
без реальних витрат на AI.

Рішення:
Використовувати mock-провайдер.
Основна майбутня модель — Qwen3 через Ollama.

Наслідки:
Можна тестувати всі шари без API-ключа.
Mock не доводить якість справжньої моделі.
Перевірка реального AI відбудеться в ПР15.
