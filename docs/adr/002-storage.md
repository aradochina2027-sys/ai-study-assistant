# ADR-002. Сховище

Контекст:
Проєкт призначений для одного користувача
й локальної демонстрації.

Рішення:
Використовувати SQLite для запитів,
результатів і станів.
Навчальні матеріали зберігати у файлах.

Наслідки:
Не потрібен окремий сервер бази даних.
Для тестів можна використовувати
тимчасову SQLite-базу.
