# Навчальні нотатки

## Git

Git — система контролю версій.

git init — створення нового Git-репозиторію.

git status — перегляд стану файлів.

git add — додавання змін до індексу.

git commit — збереження змін у локальній
історії репозиторію.

git push — надсилання комітів у віддалений
репозиторій.

## Python

list — впорядкована змінювана колекція
елементів Python.

dict — колекція пар ключ-значення.

Значення у словнику можна отримати за ключем.

try/except — конструкція обробки винятків.

## SQL

VIEW — віртуальна таблиця, визначена запитом.

Представлення створюють командою
CREATE VIEW ... AS SELECT ...

INDEX — структура для прискорення певних
операцій пошуку у таблицях.

PRIMARY KEY — обмеження для унікальної
ідентифікації рядків таблиці.
