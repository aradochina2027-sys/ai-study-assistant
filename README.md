# AI Study Assistant

Інтелектуальний помічник для пошуку інформації
у власних навчальних матеріалах.

## Користувач
Студент, який працює з конспектами та
інструкціями до практичних робіт.

## Основний сценарій
Користувач ставить запитання, система шукає
відповідні фрагменти документів і формує
відповідь із посиланням на джерело.

## Технології (заплановано)
- Python
- FastAPI
- Ollama / Qwen3 4B
- Семантичний пошук (RAG)

## Статус
ПР13: вибір теми та постановка задачі.

Реалізацію застосунку заплановано на ПР14–ПР20.
